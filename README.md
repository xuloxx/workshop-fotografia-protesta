# Workshop de Fotografía de Protestas y Marchas

Landing estática del workshop organizado por BackFocus (sábado 14 de noviembre de 2026, Santiago).

## Publicar en Render

1. Sube esta carpeta a un repositorio de GitHub.
2. En Render: **New → Static Site** y conecta el repositorio.
3. Deja *Build Command* vacío y usa `.` como *Publish Directory*.

También puedes usar **New → Blueprint**: Render lee `render.yaml` y crea el sitio solo.
